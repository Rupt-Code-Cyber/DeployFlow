# DeployFlow Security Policy

We treat software supply-chain integrity and runtime cloud vulnerability patching as high priorities.

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | ❤️ Active Support |

## Reporting a Vulnerability
Do not expose suspected platform vulnerabilities or security leaks on public repository issues.

Please flag identified security vulnerabilities or cloud exposure pathways via private coordination. Contact the platform architect directly to coordinate an assessment and deployment patch window.

## Automated SecOps Baselines
Every pull request is automatically subjected to:
- Static Application Security Testing (SAST).
- Dependency Vulnerability Scanning.
- Secret Leak Detection Scans.
